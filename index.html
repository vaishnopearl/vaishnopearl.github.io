🗑️ Remove Accidental Month Entry

Use this only to remove a month that was opened by mistake (e.g. a future month with no payments recorded). Months that already have paid flats or expenses will ask for extra confirmation before deleting.

🛠️ Fix Historical Months

If real payment tracking in this app only started partway through, older months will wrongly show every flat as unpaid — even if everyone actually paid. Use this to correct that in one step. This updates the Defaulters report, Balance Sheet, Annual Report, and Carry Forward Balance all at once.

💾 Backup & Restore (important)
☁️ Cloud Sync ☁️ live sync on
Changes now sync automatically to everyone. The buttons below are only for manual backup/restore if ever needed.

All data is stored only on this phone. Download a backup regularly and keep it safe — email it to yourself or save it to Google Drive. If this phone is lost, reset, or the app data is cleared, you can restore everything from a backup file.

Restore replaces everything. Merge only adds records that are missing — nothing already here is deleted or changed.
Tip: download a fresh backup after every month's entries.
☁️ Automatic Cloud Backups

If the daily backup Cloud Function is deployed, a snapshot is saved automatically every night — no one needs to remember to click anything. Fetch the most recent one here anytime.

Opens your phone's share sheet with the backup file attached — pick Gmail and send. This one file holds all data and every uploaded bill/document. (Sending must be done by you each time — it can't send on its own.)
